# Oakenforge Portfolio Clean Room

This repository is an intentionally narrow, public-by-nature snapshot of the owner’s public portfolio front end at https://oakenforge.cc/.

It contains only allowlisted browser-delivered HTML, CSS, and JavaScript needed to address defects observed by the local Lighthouse, axe, and responsive audit. It excludes Git history, the private source repository, the Cloudflare Worker, deployment configuration, environment files, admin/CMS/back-office code, private paths, and customer data.

Changes produced here are patches for local review and manual staging back into the canonical source. This repository does not deploy.
